# Тестовое задание: учёт рабочего времени

Создайте с нуля небольшое веб-приложение для учёта рабочего времени сотрудников компании. Используйте нейросети для написания кода; язык, стек и ИИ-модели выбирайте сами.

## Что должно работать

- добавление сотрудников;
- запуск и остановка таймера с описанием задачи;
- просмотр записей и общего времени каждого сотрудника за выбранный период;
- сохранение данных после перезапуска приложения.

Достаточно простого интерфейса. Авторизация и сложные роли не нужны. Используйте только вымышленные данные.

## README

В README опишите:

- запуск;
- использованные ИИ-инструменты и модели;
- несколько примеров запросов к ним;
- какие ошибки в коде вы нашли и исправили.

Добавьте проверки основных сценариев, включая повторный запуск таймера и пустой отчёт.

## Критерии оценки

Оцениваем работающий результат, понятный код, осмысленное применение ИИ и вашу способность объяснить и доработать решение.
